# Using the help center

This page is the framework's **worked example of the media pipeline**: every image below is regenerated by one command from `tools/media/help-center.json`, and the video comes from a recorded Playwright flow. The subject happens to be this docs site itself, which is what lets the example ship without a product app behind it.

Copy this page's shape when you document your own modules.

## How this page's media is produced

<Steps>

1. Serve the site you are shooting:

   ```bash
   npm run build
   npm run serve -- --port 3300 --no-open
   ```

2. Regenerate every image from the manifest:

   ```bash
   npm run media -- --manifest tools/media/help-center.json --base http://localhost:3300
   ```

3. Recompress before committing:

   ```bash
   npm run media:optimize
   ```

</Steps>

Nothing here is shot by hand. When the UI changes, the same command shoots the whole set again, and `npm run media -- --manifest tools/media/help-center.json --check` reports which images no longer match.
