# Managing projects

<Badge variant="admin">Admin</Badge> <Badge variant="info">Free plan: 3 active projects</Badge>

A project groups related work, members, and settings. This guide walks you through creating one.

## Before you begin

- You need the **Admin** role in the workspace.
- On the Free plan you can have up to 3 active projects — archive one to free a slot.

## Steps

<Steps>

1. Open **Settings**.

2. Select **Projects**.

   <Figure
     src="/img/placeholder/dashboard.svg"
     alt="Dashboard with the sidebar navigation open, showing stat cards and the projects area"
     caption="The dashboard — projects are managed from the sidebar."
     frame="browser"
   />

3. Select **New project**.

4. Enter a name.

5. Select **Create**.

</Steps>

## Verify

The project appears in your sidebar. Other workspace members see it once you add them as project members.
