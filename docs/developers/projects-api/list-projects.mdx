# List projects

<ApiEndpoint method="GET" path="/v1/projects">Returns projects in the workspace, newest first.</ApiEndpoint>

<Badge variant="info">Member role or higher</Badge> <Badge variant="info">All plans</Badge>

## Overview

Returns every project the API key's role can see, newest first, with cursor pagination. Use it to sync project lists into your own systems or to resolve a project `id` by name.

## Request

### Query parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `status` | string | No | Filter by `active` or `archived`. Default: both. |
| `limit` | integer | No | Page size, 1–100. Default: 25. |
| `cursor` | string | No | `next_cursor` value from a previous response. |

## Response

`200 OK` — an array of [project objects](/developers/projects-api/#the-project-object) plus a pagination cursor:

```json
{
  "data": [
    {
      "id": "proj_8fK2m",
      "name": "Quarterly report",
      "status": "active",
      "members": 4,
      "created_at": "2026-07-01T09:30:00Z",
      "updated_at": "2026-07-20T14:05:12Z"
    }
  ],
  "next_cursor": "cur_9hT3p"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `data` | array | Project objects, newest first. |
| `next_cursor` | string \| null | Pass as `cursor` to fetch the next page. `null` on the last page. |

## Status and error codes

| Status | Code | When |
| --- | --- | --- |
| `200` | — | Success, including an empty `data` array. |
| `400` | `invalid_parameter` | `status` isn't `active`/`archived`, or `limit` is outside 1–100. |
| `401` | `unauthenticated` | Missing, malformed, or revoked API key. |
| `429` | `rate_limited` | Too many requests — wait for `X-RateLimit-Reset`. |
| `5xx` | `server_error` | Server problem — retry with exponential backoff. |

## Business rules

- Results are scoped to the key's workspace — there's no cross-workspace listing.
- Members see only projects they belong to; Admin keys see every project.
- Cursors expire after 10 minutes; restart from the first page if a cursor is rejected.
- Archived projects stay listed (with `status: "archived"`) until deleted.
