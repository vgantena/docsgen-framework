# Retrieve a project

<ApiEndpoint method="GET" path="/v1/projects/{id}">Returns one project by id.</ApiEndpoint>

<Badge variant="info">Member role or higher</Badge> <Badge variant="info">All plans</Badge>

## Overview

Fetches the current state of a single project. Use it to refresh one record instead of re-listing everything — for example after receiving a webhook event.

## Request

### Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | Yes * | Project identifier, for example `proj_8fK2m`. |

## Response

`200 OK` — the [project object](/developers/projects-api/#the-project-object):

```json
{
  "id": "proj_8fK2m",
  "name": "Quarterly report",
  "status": "active",
  "members": 4,
  "created_at": "2026-07-01T09:30:00Z",
  "updated_at": "2026-07-20T14:05:12Z"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | Unique identifier, prefixed `proj_`. Stable for the project's lifetime. |
| `name` | string | Display name, 1–120 characters. Unique within the workspace. |
| `status` | string | `active` or `archived`. Archived projects are read-only. |
| `members` | integer | Count of workspace members with access. |
| `created_at` | string | ISO 8601 creation timestamp (UTC). |
| `updated_at` | string | ISO 8601 timestamp of the last change (UTC). |

## Status and error codes

| Status | Code | When |
| --- | --- | --- |
| `200` | — | Success. |
| `401` | `unauthenticated` | Missing, malformed, or revoked API key. |
| `403` | `access_denied` | The key's user isn't a member of this project. |
| `404` | `resource_not_found` | No project with this `id` in the workspace — including deleted projects. |
| `429` | `rate_limited` | Too many requests — wait for `X-RateLimit-Reset`. |
| `5xx` | `server_error` | Server problem — retry with exponential backoff. |

## Business rules

- A `404` is returned (not `403`) when the project belongs to a different workspace, so ids can't be probed.
- Deleted projects are gone: retrieval returns `404`, with no tombstone record.
- Archived projects return normally with `status: "archived"`.
