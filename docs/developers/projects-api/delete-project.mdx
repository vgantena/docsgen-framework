# Delete a project

<ApiEndpoint method="DELETE" path="/v1/projects/{id}">Permanently deletes a project and everything in it.</ApiEndpoint>

## Overview

Permanently removes a project, its tasks, and its member associations. There is no undo and no recycle bin.

<Badge variant="admin">Admin role</Badge> <Badge variant="new">All plans</Badge>

:::warning
Deletion cascades to **all tasks and files** in the project. If the data may be needed later, [archive instead](/developers/projects-api/update-project) — `PATCH /v1/projects/{id}` with `{"status": "archived"}`.
:::

## Request

### Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | Yes | Project identifier, for example `proj_8fK2m`. |

## Response

`204 No Content` — empty body on success.

## Status and error codes

| Status | Code | When |
| --- | --- | --- |
| `204` | — | Project deleted. |
| `401` | `unauthenticated` | Missing, malformed, or revoked API key. |
| `403` | `insufficient_role` | Key's role is below Admin. |
| `404` | `resource_not_found` | No project with this `id` — including one already deleted. |
| `429` | `rate_limited` | Too many requests — wait for `X-RateLimit-Reset`. |

## Business rules

- Deletion is **permanent** — data is unrecoverable once the request returns `204`.
- Cascades: all tasks, files, and member associations in the project are removed.
- Deleting an already-deleted project returns `404`, so a retried delete is safe to treat as success.
- Fires `project.deleted` to all [webhook subscriptions](/developers/webhooks); the event carries the final state of the object.
- A deleted project's name becomes available for reuse immediately.
