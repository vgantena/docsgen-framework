# Files API

A file belongs to exactly one project. Deleting the project deletes its files —
see [Delete a project](/developers/projects-api/delete-project).

## The file object

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | File identifier, for example `file_2Bd7q`. |
| `project_id` | string | The project the file belongs to. |
| `name` | string | Original file name, 1–255 characters. |
| `size_bytes` | integer | Size on disk. |
| `uploaded_at` | string | Timestamp of the upload. |

## Endpoints

| Endpoint | Purpose |
| --- | --- |
| [`POST /v1/projects/{id}/files`](/developers/files-api/upload-file) | Upload a file to a project. |
| [`DELETE /v1/files/{id}`](/developers/files-api/delete-file) | Delete a file. |
