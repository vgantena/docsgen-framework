# Delete a file

<ApiEndpoint method="DELETE" path="/v1/files/{id}">Permanently deletes the file and frees its storage.</ApiEndpoint>

<Badge variant="info">Member role or higher</Badge> <Badge variant="info">All plans</Badge>

## Overview

Deletes one file from its project. The storage allowance is credited back
immediately.

:::warning
There is no recycle bin. A deleted file cannot be recovered — download it first
if you may need it later.
:::

## Request

### Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | Yes * | File identifier, for example `file_2Bd7q`. |

## Response

`204 No Content` — an empty body.

## Status and error codes

| Status | Code | When |
| --- | --- | --- |
| `204` | — | Deleted. |
| `401` | `unauthenticated` | Missing or invalid API key. |
| `403` | `forbidden` | Viewers cannot delete files. |
| `404` | `not_found` | No file with that id, or it was already deleted. |
| `5xx` | `server_error` | Server problem — retry with exponential backoff. |

## Business rules

- Deletion is immediate and permanent; there is no retention window.
- Storage is credited back to the project as soon as the call returns.
- Any member role or higher can delete a file, including files somebody else uploaded.
