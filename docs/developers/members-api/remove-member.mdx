# Remove a member

<ApiEndpoint method="DELETE" path="/v1/members/{id}">Revokes access and cancels any outstanding invitation.</ApiEndpoint>

<Badge variant="admin">Admin role</Badge> <Badge variant="info">All plans</Badge>

## Overview

Removes the member from the workspace. Work they created stays where it is —
only their access ends.

:::warning
Access ends immediately across every project in the workspace. There is no
grace period and no undo; invite the person again to restore access.
:::

## Request

### Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | Yes * | Member identifier, for example `mem_4Qp1x`. |

## Response

`204 No Content` — an empty body.

## Status and error codes

| Status | Code | When |
| --- | --- | --- |
| `204` | — | Removed. |
| `401` | `unauthenticated` | Missing or invalid API key. |
| `403` | `forbidden` | The caller is not an admin. |
| `404` | `not_found` | No member with that id in this workspace. |
| `409` | `last_admin` | The workspace would be left with no admin. |
| `5xx` | `server_error` | Server problem — retry with exponential backoff. |

## Business rules

- A workspace keeps at least one admin, so removing the last one fails.
- Removing a member whose invitation is outstanding cancels that invitation.
- Projects, files, and comments the member created are retained.
